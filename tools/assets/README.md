# Asset generator

Every SVG in `/assets` (except `brand/`) is generated by `build.py`.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python build.py
```

- `fonts/`: Grenze (SIL OFL). Converted to outlines, never loaded as a webfont.
- `icons/`: technology logos from simple-icons (CC0).
- Colors, radius and copy live at the top of `build.py` and in `__main__`.
